# MyDigiDiary-Website
A personal digital diary website with themes, diary entries, and photo memories.
📔 MyDigiDiary – Personal Digital Diary Website

MyDigiDiary is a personal digital diary website designed to help users capture their daily thoughts, preserve special memories, and express themselves in a personalized digital space. With diary entries, photo memories, and customizable themes, it offers a simple and creative way to document everyday life.

🌐 Live Website: https://myydigidiary.netlify.app

✨ Features

- 📝 Diary Entries – Write and save personal thoughts, experiences, and daily memories.
- 📸 Photo Memories – Add photos to make diary entries more meaningful.
- 🎨 Customizable Themes – Personalize the appearance of your diary.
- 💖 Personal Space – Maintain a digital journal for self-expression and reflection.
- 📱 Simple Interface – Enjoy a clean and user-friendly experience.
- 🌷 Memory Keeping – Keep meaningful moments organized in one place.

🛠️ Technologies Used

- HTML5 – Structures the website content.
- CSS3 – Handles styling, layouts, and visual themes.
- JavaScript – Adds interactivity and manages diary features.
- Netlify – Hosts the live website.

💻 Getting Started

To run this project locally:

1. Clone the repository:
   
   git clone https://github.com/jyotikundu2731/MyDigiDiary-Website.git

2. Open the downloaded project folder.

3. Locate "index.html".

4. Open "index.html" in your web browser.

No build process is required for a basic HTML, CSS, and JavaScript version.
